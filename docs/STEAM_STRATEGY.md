# Estrategia de Publicación en Steam — ECOS DEL LABERINTO

## Posicionamiento

Puzzle de manipulación temporal con **mecánica de ecos persistentes**: fácil de aprender,
difícil de dominar, profundamente rejugable y pensado para speedruns. Tono sci-fi "Chronos Labs".

- **Géneros/tags:** Puzzle, Top-Down, Time Manipulation, Singleplayer, Puzzle-Platformer,
  Atmospheric, Sci-fi, Difficult, Speedrun.
- **Referentes (para storepage y prensa):** *Braid*, *The Talos Principle*, *Patrick's Parabox*,
  *Cosmic Express*, *Baba Is You* (como vecindario de mercado, no como clones).
- **Gancho de una frase:** "Cada muerte deja un eco. Coordina tus yos del pasado para escapar
  del Laberinto Temporal."

## Página de Steam (Steamworks)

- **Capsule art** claro y legible a tamaño pequeño; título + hook visual del eco.
- **Tráiler** de 45–75 s mostrando el "momento ajá": morir → el eco repite → resuelves el puzzle.
- **GIFs** en la descripción de los 3 verbos clave (crear eco, bloquear láser, mantener botón).
- **Bullets** de features: ecos persistentes, 4 personajes con habilidades únicas, 65 niveles +
  jefe, 3 estrellas y cristales, reliquias, logros, Steam Deck Verified, speedrun-friendly.
- Demo publicada y enlazada (clave para wishlists).

## Wishlists primero (pre-lanzamiento)

1. **Publicar la página "Coming Soon" pronto** (acumular wishlists desde el día 1).
2. **Demo** lista para **Steam Next Fest** (mayor pico de wishlists para indies).
3. Contenido orgánico: GIFs en redes (X, Reddit r/IndieGaming, r/puzzlegames), TikTok/Shorts
   con el bucle muerte→eco→solución; devlogs.
4. Contactar curators y prensa/streamers de puzzles con claves de la demo.

## Precio y modelo

- **Precio sugerido:** 9.99–14.99 USD (premium, **sin pay-to-win**; la economía de Fragmentos
  es sólo cosmética y desbloqueo de personajes con juego).
- **Descuento de lanzamiento:** 10–15% durante la primera semana para impulsar el ranking.
- Sin microtransacciones. Posibles DLC de mundos/cosméticos tras 1.0.

## Logros y características Steam

- Mapear `AchievementData.SteamApiName` a logros reales de Steamworks (los 25 ya definidos).
- Steam Cloud para el save JSON.
- **Steam Input** para mando y **Steam Deck Verified** (texto legible, controles, 60 fps).
- Trading cards / puntos como extra de comunidad (opcional, post-launch).

## Calendario de lanzamiento

| Hito | Acción |
|---|---|
| T-3 meses | Página "Coming Soon" + tráiler teaser; empezar wishlists. |
| T-6 semanas | Demo pulida del Mundo 1; inscripción a Next Fest. |
| Next Fest | Demo en vivo, streams, prensa, pico de wishlists. |
| T-2 semanas | Build candidata, certificación Deck, localización ES/EN. |
| Lanzamiento | 1.0 con descuento de estreno; empuje en redes/curators. |
| Post-launch | Parches, modo speedrun/tablas, contenido comunitario, DLC. |

## Métricas a vigilar

- Conversión wishlist→venta, reseñas (objetivo "Muy positivas"), tiempo medio de sesión,
  tasa de finalización por mundo, embudo de la demo (instalan→terminan→wishlist).

## Checklist de certificación

- [ ] Build sin bloqueantes en PC y Steam Deck.
- [ ] Logros, Cloud e Input integrados y probados.
- [ ] Localización mínima ES/EN.
- [ ] Página completa (capsules, tráiler, screenshots, descripción, tags, edad/contenido).
- [ ] Demo publicada.
